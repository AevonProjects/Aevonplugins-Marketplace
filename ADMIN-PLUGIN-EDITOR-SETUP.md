# Aevon Marketplace — Advanced Plugin Editor Setup

Run `supabase/plugin-listing-content.sql` once in Supabase SQL Editor before using the new editor.

The Admin plugin form now supports:
- Plugin name and version
- Price / publish state
- JAR upload directly from the editor
- Rich description with emoji, bold, italic, underline, fonts, text sizes, colors, and lists
- 3 carousel image slots
- Each image: maximum 5 MB and minimum 500×500 px
- Wiki URL
- YouTube tutorial URL
- Discord URL

The public plugin details page now displays the image carousel, rich description, and available resource links.
