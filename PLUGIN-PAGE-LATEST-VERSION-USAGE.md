# Plugin page latest-version + usage update

- The plugin title now always prioritizes the newest **published uploaded release** from `plugin_versions` by upload time.
- Uploading ALicense 1.1.2 after 1.1.1 makes the title display **ALicense v1.1.2** automatically.
- The ALicense usage analytics section was moved to the **very bottom** of the plugin page, after Reviews and Version History.
- The bottom analytics section now focuses on a single 30-day **server adoption graph** and clearly shows Currently Active, Total Servers, and Unique Players Seen.
- Server counts are based on unique licensed installations; restarts do not create additional server installations.
