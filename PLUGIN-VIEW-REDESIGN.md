# Plugin View Redesign

This build changes the public plugin detail page to a compact resource-marketplace style layout.

## Changes
- Removes the repeated short description from the top header.
- Shows the rich admin description only once in the main Description section.
- Compact plugin name + version header.
- Resource-style top navigation for Overview, Wiki, YouTube Tutorial, and Discord.
- Large carousel/preview on the left.
- Sticky right sidebar for price, Purchase/Download, ownership, license, plugin information, and resource links.
- Keeps the existing GCash manual checkout, QR code, Discord verification, ownership, licensing, and secure download behavior.
