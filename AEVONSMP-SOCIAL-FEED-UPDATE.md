# AevonSMP Social Feed Update

The AevonSMP community area now uses a social-post layout instead of a traditional thread list.

## What changed
- The main `/aevonsmp` page now shows recent Community Posts directly.
- Posts display the author's website profile picture, nickname, member/admin/verified label, timestamp, text, image/video, reaction count, and comment count.
- The dedicated `/aevonsmp/forum` page is now a scrolling post feed.
- Images and videos are displayed inline like a normal social-media post.
- Reactions and comments remain available from the full community page.
- Existing Forum Credit rules, deletion/refund rules, comments/replies, and media limits are unchanged.

No new Supabase SQL or Minecraft plugin update is required for this visual/feed update.
