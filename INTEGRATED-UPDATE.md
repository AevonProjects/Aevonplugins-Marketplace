# Integrated update

This package combines:

- PayPal + GCash purchase flows
- Marketplace plugin licenses and first-server activation binding
- ALicense anonymous usage graphs (servers + unique hashed players)
- Admin Plugin License Manager (search/filter, activate/suspend/revoke, reset server activation)
- Plugin Version History and old-release downloads
- Automatic latest-version display title
- License-validation owner acknowledgement support for ALicense

For usage analytics, run `supabase/alicense-usage-and-license-admin.sql` once in Supabase SQL Editor if it has not already been run.
