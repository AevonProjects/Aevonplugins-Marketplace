# Plugin Resource Layout Update

The plugin detail page has been redesigned to follow the compact resource-page reference while preserving the Aevon dark theme and existing marketplace features.

## What changed
- Compact plugin title/header with the latest version and a prominent Download/Purchase button.
- Resource-style navigation tabs: Overview, Documentation, Reviews, Version History, Usage (ALicense), Discussion.
- Dense two-column layout with the main description/gallery on the left and stacked information/version/license/resource cards on the right.
- Version History remains available with rollback downloads for owners.
- ALicense usage analytics remains integrated.
- Existing PayPal, GCash, ownership, licensing, reviews, and secure download flows are preserved.

No Supabase migration is required for this visual/layout update.
